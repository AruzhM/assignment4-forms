# Campus Club — Forms and Validation

Assignment 4 for Web Technologies.

## Author

Marat Aruzhan

## Description

Campus Club is a student club website with contact forms
and a registration form. The project demonstrates HTML5
validation, Bootstrap form styling, and validation feedback.

## Pages

- index.html — basic contact form.
- validation.html — contact form with HTML5 validation.
- bootstrap.html — contact form styled with Bootstrap Grid.
- feedback.html — contact form with valid and invalid feedback.
- registration.html — club registration form.

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open index.html in a browser.
3. Use the navigation bar to switch between pages.

An internet connection is required to load Bootstrap from the CDN.

## Validation

Contact forms demonstrate required fields, email format
validation, and text length limits.

The registration form includes a minimum password length
of 8 characters and checks that both passwords match.
Gender and country are required. Hobbies are optional.

The registration form is a frontend demonstration.
It does not create accounts or store data on a server.
